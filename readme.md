# Individual Assignment 3

This is my third individual assignment in HTML, CSS and JavaScript at Kristiania.

I made a music playlist app where users can browse a collection of 23 songs, search by title or artist, filter by genre, and sort by title, artist or duration.

Users can add and remove songs from their playlist, clear the entire playlist, and see the total duration. The playlist is saved in the browser using localStorage.

I used HTML, CSS and JavaScript to create the website, make it responsive, and implement the interactive features.
